Bem-vindo(a) ao meu repositório de estudos e projetos práticos na área de Garantia de Qualidade de Software (QA)! 🚀

Este espaço foi criado para documentar minha jornada de aprendizado, aplicação de conceitos e evolução prática como Analista de Testes / QA Junior. Aqui você encontrará projetos que cobrem desde os fundamentos do teste manual até a criação de suítes de testes automatizados.

Estou em transição/início de carreira focado em Qualidade de Software, buscando minha oportunidade como QA Junior. Tenho me dedicado a aprender boas práticas de teste, ciclo de vida de bugs, escrita de cenários e automação para garantir entregas de software robustas, confiáveis e alinhadas aos requisitos de negócio.

📚 Conteúdo do Repositório

1. 📝 Testes Manuais (Manual Testing)

Documentação de Testes: Elaboração de Planos de Teste (Test Plans), Mapeamento de Requisitos e Matriz de Rastreabilidade.

Casos de Teste & Cenários: Escrita em formato tradicional e uso de sintaxe BDD (Behavior-Driven Development / Gherkin - Dado/Quando/Então).

Gestão & Reporte de Bugs: Relatórios detalhados de defeitos (Bug Reports) contendo passos para reprodução, evidências (logs/screenshots), severidade e prioridade.

Técnicas de Design de Testes:

Particionamento de Equivalência

Análise de Valor Limite

Tabela de Decisão

Transição de Estados

2. 🤖 Testes Automatizados (Automated Testing)

Automação Web: Testes End-to-End (E2E) simulando a navegação do usuário final.

Automação de API (REST): Validação de endpoints, status codes, contrato e carga útil (payload) JSON.
